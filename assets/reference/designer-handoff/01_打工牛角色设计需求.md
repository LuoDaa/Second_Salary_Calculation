# 01｜打工牛角色设计需求

项目：打工牛 · 实时工资计算器  
角色名：打工牛 996 号  
用途：网页端「打工牛剧场」+ 后续桌宠小窗  
最终动画技术：Spine 2D + PixiJS  
最终需要导出：`work-cow.json`、`work-cow.atlas`、`work-cow.png`

---

## 1. 角色定位

这是一个「上班时陪用户实时看工资增长」的打工陪伴角色。

关键词：

- 疲惫但努力
- 可爱但不幼稚
- 社畜感
- 赚钱感
- 暗色高级 App 吉祥物
- 2.5D / 潮玩 / 游戏 UI 质感

不要做成普通农场奶牛，也不要做成儿童贴纸牛。

---

## 2. 核心构图

必须是：

> 上半身坐在电脑桌后的小牛，桌子遮挡身体下半部分。

推荐构图：

```text
背景弱化显示器
        ↓
小牛大头 + 上半身
        ↓
双手连接袖子，放在键盘上
        ↓
桌面挡住身体下半部分
```

不要做：

- 全身站立小牛
- 正圆脸小牛
- 漂浮耳朵
- 漂浮双手
- 角像两枚硬币贴上去
- 桌子直接切断脖子

---

## 3. 外观设定

### 头部

- 头部是圆润但不规则的头型，不允许正圆。
- 脸颊可以略鼓，下巴略收。
- 头部占角色视觉高度的 50% - 60%。
- 采用 3/4 轻微角度，不要完全正面贴纸感。
- 眼睛半睁，有一点困，但不是丧。
- 鼻口区域要融合进脸部，不要像贴纸。
- 额头可以有一块焦糖色斑纹，但必须贴合头型结构。

### 耳朵和牛角

- 耳朵从头部后方长出，有遮挡关系。
- 牛角是小金角，有金币质感，但不要像两个硬币贴上去。
- 牛角需要能在 `coin_pop` 动画里发光。
- 耳朵可跟随头部轻微延迟摆动。

### 身体和服装

- 白衬衫 + 深蓝马甲 + 薄荷绿领带。
- 胸前有小工牌：`WORK COW`。
- 必须露出肩膀和袖子，避免头直接贴在桌子上。
- 领带要能轻微摆动。

### 手和键盘

- 双手必须从袖子/手臂延伸到键盘。
- 不允许只有两个小手漂浮在键盘上。
- 手部需要适合做打字循环动画。
- 键盘需要有发光按键，可与打字动作同步闪烁。

### 背景显示器

- 显示器只作为氛围，不抢主体。
- 屏幕内容建议只保留：
  - `¥ 137.45`
  - `WORKING...`
  - 少量代码流
- 亮度和透明度要弱于小牛主体。

## 4. 色彩规范

建议色值：

| 用途 | 色值 |
|---|---|
| 背景深色 | `#070B12` |
| 卡片深色 | `#0B1220` |
| 小牛身体 | `#FFF1D6` |
| 脸部阴影 | `#E9CFA3` |
| 焦糖斑纹 | `#C98A4A` |
| 深咖描边 | `#5B3A24` |
| 金色牛角 | `#F7C948` |
| 深蓝马甲 | `#16243A` |
| 薄荷绿领带 | `#7CFFB2` |
| 青绿色边缘光 | `#5EF2C2` |
| 腮红 | `#FF9DAA` |

整体风格要能融入暗色赛博 UI。

请先交付以下 PNG 预览图确认风格：

   正常工作状态，坐在电脑前敲键盘。

---

## 6. 禁止项

严禁出现：

- 正圆牛头
- 儿童贴纸风
- 农场风
- 漂浮五官
- 漂浮双手
- 无肩膀连接
- 全身站立
- 过多金币
- 背景过于复杂
- 廉价小游戏风
- 过大的表情包式笑脸
- 过于拟人化的人形牛娘

---

## 7. 设计验收标准

静态图放进当前页面的「打工牛剧场」里，应满足：

- 第一眼能看出是“打工牛”，不是普通牛。
- 不像贴纸，不像 SVG 拼图。
- 角色主体和暗色 UI 融合。
- 手、身体、键盘有真实连接关系。
- 即使不动，也有高级产品 IP 感。
